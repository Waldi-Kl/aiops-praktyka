Asystent w terminalu: pętla, bramka, granica danych

Claude Code, Copilot CLI i Codex działają tak samo: model u dostawcy decyduje, którego narzędzia użyć, a CLI na Twoim laptopie je uruchamia. Przed każdym uruchomieniem stoi bramka uprawnień. Wszystko, co agent przeczyta, trafia do modelu.

Jak przebiega jedno zadanie w Claude Code (tak samo w Copilot CLI i Codex)

  1. Zadanie i kontekst. Wpisujesz zadanie. CLI dokłada pliki instrukcji: CLAUDE.md (poziomy: firma → użytkownik → projekt → katalog), AGENTS.md, w Copilocie .github/copilot-instructions.md.
  2. Zapytanie do modelu. Do dostawcy idzie prompt, instrukcje i wszystko, co agent już przeczytał lub uruchomił. Tu dane opuszczają firmę. Ochrona zaczyna się od planu firmowego bez trenowania na danych i umowy DPA.
  3. Odpowiedź modelu. Model zwraca tekst albo prośbę o narzędzie, np. „przeczytaj plik” albo „uruchom kubectl get pods”. Sam niczego nie uruchamia.
  4. Bramka uprawnień. CLI sprawdza reguły: allow uruchamia, ask pyta Ciebie, deny blokuje, np. Read(./.env) albo Bash(kubectl delete:*). Reguły deny z poziomu firmy nie dają się nadpisać. Copilot CLI ma tu --allow-tool / --deny-tool, Codex dodatkowo sandbox systemu.
  5. Wykonanie z Twoimi poświadczeniami. Narzędzie działa z Twoim kubeconfigiem, profilem AWS i tokenami serwerów MCP. Wynik trafia do historii i wraca do kroku 2. Pętla kręci się, aż model odda odpowiedź zamiast prośby o narzędzie.

Czym różnią się trzy narzędzia: te same pliki, inni dostawcy, inna ochrona domyślna

Co z tego wynika

Agent ma Twoje uprawnienia

Kubeconfig z cluster-admin i profil AWS z prawem do terraform apply działają też dla agenta. Daj mu osobne poświadczenia tylko do odczytu.

Co przeczyta, to wyśle

.env, *.tfstate i wynik kubectl describe stają się kontekstem dla modelu. Zablokuj je regułą deny, zanim agent je otworzy.

Para narzędzie + model

Ten sam model często działa lepiej w „swoim” narzędziu. Po demie porównujemy pary, a nie same narzędzia.

Tryb „yolo” tylko w kontenerze

Pominięcie pytań wyłącza bramkę z kroku 4. Używaj tego tylko w izolowanym, jednorazowym kontenerze.
