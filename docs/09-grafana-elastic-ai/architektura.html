Grafana Assistant: myśli w chmurze, pyta Twoje dane

Assistant zamienia pytanie na PromQL albo LogQL, wykonuje je na Twoim źródle danych i tłumaczy wynik. Myśli zawsze w Grafana Cloud, także gdy Grafana stoi u Ciebie. Do chmury trafia prompt i wyniki zapytań, które agent odczytał. Elastic różni się głównie tym, że model wybierasz sam.

Jak przepływa jedno pytanie do Grafana Assistant

  1. Pytanie. Piszesz w panelu bocznym, np. „pokaż p95 latencji dla checkout z ostatniej godziny”. Grafana wysyła prompt z kontekstem (źródła danych, dashboard) do backendu Assistanta. Backend jest zawsze w Grafana Cloud, także przy Grafanie self-hosted.
  2. Model pisze zapytanie. LLM, którego nie wybierasz, zamienia pytanie na PromQL, LogQL albo TraceQL. Tu powstają błędy: złe etykiety, nieistniejące metryki.
  3. Wykonanie u Ciebie. Zapytanie trafia do Prometheusa albo Lokiego z uprawnieniami zalogowanego użytkownika (RBAC, dostęp do datasource'ów). Assistant nie zobaczy więcej niż Ty.
  4. Wyniki wracają do modelu. Odczytane serie i linie logów idą do Grafana Cloud razem z promptem. Źródło danych zostaje u Ciebie, ale wyniki nie. PII i sekrety w logach maskujemy przy ingestii, zanim trafią do Lokiego.
  5. Odpowiedź. Model tłumaczy wynik i pokazuje zapytanie, którego użył.
  6. Weryfikacja. Kopiujesz zapytanie do Explore i sprawdzasz na danych: czy etykiety istnieją, czy funkcje i okno czasowe mają sens. To ćwiczenie z lab05.

Grafana, Elastic i darmowa droga: gdzie stoi model i dokąd idą dane

Co z tego wynika

„U siebie” to nie offline

Backend Assistanta jest zawsze w Grafana Cloud. Wyniki zapytań, które agent odczytał, wychodzą razem z promptem. Region stacka: EU.

Każde zapytanie sprawdzamy

Assistant myli etykiety i wymyśla metryki. PromQL/LogQL odpalamy w Explore, zanim uwierzymy w odpowiedź. Modele lepiej piszą ES|QL niż złożony Query DSL.

Model to decyzja dostawcy albo Twoja

Grafana: bez wyboru modelu, bez air-gap. Elastic: własny konektor, także lokalny model. Agent Builder nie ma jeszcze Knowledge Base ani anonimizacji.
