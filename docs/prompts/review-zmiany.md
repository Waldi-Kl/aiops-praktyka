# Review zmiany

Skopiuj blok niżej i uzupełnij pola `<...>`. Dane wklejaj przycięte i zredagowane (bez haseł, kluczy, danych osobowych).

```text
Zrób review poniższej zmiany jako recenzent <bezpieczeństwa / niezawodności / kosztów>.
Kontekst: <co zmiana ma robić, ticket, środowisko docelowe>.
Diff:
<git diff>
Ograniczenia: komentuj tylko zmienione linie. Nie proponuj zmian stylistycznych.
Jeśli nie masz uwag w danej kategorii, napisz „brak".
Format: lista | plik:linia | ryzyko (wysokie/średnie/niskie) | propozycja |.
```
